OVERVIEW
--------
Add volumetric smoke rendering to the OpenGL Engine using NanoVDB. This plan
uses NanoVDB (not full OpenVDB) because:

  - Header-only library: No complex build dependencies, just #include
  - GPU-friendly design: Optimized for real-time rendering
  - OpenGL/GLSL compatible: Works without CUDA dependency
  - Lightweight: Single header file (NanoVDB.h) contains core data structure
  - Real-time capable: Designed for interactive applications

NANOVDB INTEGRATION APPROACH
----------------------------
Option A: CPU-side NanoVDB + OpenGL 3D Texture (RECOMMENDED)
  - Use NanoVDB to create/load fog volume on CPU
  - Convert to 3D texture for GPU raymarching in fragment shader
  - Simpler, works with OpenGL 3.3
  - Good performance for moderate resolution volumes

Option B: Pure procedural (no NanoVDB at runtime)
  - Generate 3D noise texture directly
  - NanoVDB only used for loading pre-made VDB files
  - Simplest approach for basic smoke effects

RAYMARCHING ALGORITHM (Pseudocode)
----------------------------------
```glsl
vec3 rayOrigin = cameraPos;
vec3 rayDir = normalize(worldPos - cameraPos);

float t = 0.0;
float transmittance = 1.0;
vec3 color = vec3(0.0);

for (int i = 0; i < MAX_STEPS; i++) {
    vec3 pos = rayOrigin + rayDir * t;

    // Sample density from 3D texture
    float density = texture(volumeTexture, volumeUV(pos)).r;

    // Beer-Lambert absorption
    transmittance *= exp(-density * stepSize * absorption);

    // Accumulate color (with optional lighting)
    color += transmittance * density * smokeColor * stepSize;

    // Early exit if nearly opaque
    if (transmittance < 0.01) break;

    t += stepSize;
}
```

VOLUME TEXTURE FORMAT
---------------------
- Resolution: 64x64x64 to 128x128x128 (adjustable)
- Format: GL_R16F or GL_R32F (single channel density)
- Filter: GL_LINEAR for smooth interpolation
- Wrap: GL_CLAMP_TO_BORDER with 0.0 border

BLENDING SETUP
--------------
```cpp
glEnable(GL_BLEND);
glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA);
// Render back-to-front or use order-independent transparency
```
